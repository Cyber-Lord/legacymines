# Gallery pictures

Drop slideshow images here, then list them in `src/content/sections.ts` under `gallery.slides`.

- Landscape, at least 1600px wide, JPEG.
- Give every slide a real `alt` description.
- Leave `contain` off for photographs so they fill the frame; set `contain: true` only
  for logos or drawings that should not be cropped.

Until real pictures land, the slideshow runs on the logo files in `public/images/`.
